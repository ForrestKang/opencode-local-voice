# V0.2.0 更新说明

V0.2.0 将本地语音输入整合到 OpenCode 原生设置，并加入词表、文本整理和桌面更新恢复。录音结果写入当前草稿，检查后由用户自行发送。

## 新增

- **原生语音设置**：在 OpenCode 设置中管理麦克风、识别语言、模型和文本处理，适配宿主主题。
- **本地词表与纠错**：内置编程词表、自定义术语、纠错对照和 JSON 导入导出。
- **文本处理**：支持中文/英文标点、空格整理、编程任务和问题分析模板，以及自定义模板。
- **可选 AI 改写**：支持 OpenAI 兼容接口；默认关闭，接口不可用时保留本地结果。
- **多端接入**：Desktop、Web、TUI 和 CLI 共用本地识别服务。
- **桌面维护**：Windows 增加更新后的恢复和启动检查；macOS 支持完整应用备份与恢复。

## 修复

- 修复首次转写失败与模型加载状态处理的问题。
- 修复 Enter / Esc 未停止录音、取消后的异步结果仍写入草稿的问题。
- 修复 Windows 打开语音设置时弹出终端的问题。
- 修复点击“获取更新”时错误提示 `app.asar` 缺失，导致更新交接失败的问题。
- 修复恢复时选错备份、配置保存校验和词表限制不一致等问题。
- 整理设置页，移除示范文本和冗余结果展示。

## 使用变化

- 点击麦克风开始录音，**Enter / 结束按钮** 结束并转写，**Esc / ×** 取消当前任务。
- 普通空格键保留原有行为，空格与标点转换通过设置或文本工具操作。
- 默认启用本地轻度整理与编程词表。需要云端改写时，在设置中选择 AI 模式并配置接口。

## 安装与升级

首次安装按 [安装指南](install.md) 选择对应平台。已有 Windows 本地服务和模型时，退出 OpenCode 后使用 `windows/install-feature-preview.cmd` 更新桌面补丁；也可先通过 `-DryRun` 检查兼容性。

Windows 安装完成后使用维护后的快捷方式启动。官方 OpenCode 更新后的处理见 [更新指南](update-survival.md)；撤回补丁见 [恢复指南](recovery-v0.2.0.md)。恢复前另存安装后修改的配置。

## 已知限制

- 桌面补丁依赖可识别的 Electron/ASAR 结构，Tauri、商店包和未知布局不支持。
- Windows 自动恢复限于支持的用户级安装。未来 OpenCode 结构变化可能需要新版适配。
- macOS 桌面集成为实验性，使用 ad-hoc 签名，官方更新后需要手动重新应用补丁。
- CLI/TUI 麦克风录音需要 FFmpeg。
- 强制结束应用或断电可能丢失尚未完成的录音；请使用结束或取消操作处理当前任务。
