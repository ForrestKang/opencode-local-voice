# 语音输入设置

在 OpenCode 中打开 **设置 → 语音输入**。修改后点击保存，使配置对后续任务生效。

## 麦克风与语言

- **麦克风**：选择系统默认设备或指定麦克风。更换设备后可重新选择；系统仍需要授予麦克风权限。
- **识别语言**：自动检测、中文或 English。主要说中文或英文时可固定语言，减少短句的误判。
- **录音时预热**：提前加载模型，减少结束录音后的等待；首次加载模型仍需要时间。
- **最长录音**：可设为 5–300 秒，默认 120 秒。

点击输入框旁的麦克风开始录音。录音中的 **Enter / 结束按钮** 结束并转写；**Esc / ×** 取消当前语音任务。普通空格键保持正常输入行为。

## 文本处理

| 处理模式 | 用途 |
| --- | --- |
| 原文 | 保留识别原文 |
| 轻度整理 | 应用本地纠错、标点和空格规则，默认模式 |
| 编程任务 | 用本地模板组织编程需求 |
| 问题分析 | 用本地模板组织分析请求 |
| 自定义模板 | 将识别文字填入你提供的模板 |
| AI 改写 | 把转写文本交给配置的模型接口整理 |

**标点** 可选自动、中文标点、英文标点或保持原标点。它转换识别结果中的标点形式，不保证给没有标点的文字自动断句。

**空格处理** 默认保持空格。智能整理可调整中文词间和中英文间距；空格转逗号针对中文词组间的空格，保留普通英文词间距；逗号转空格将逗号替换为空格。这些设置只处理语音结果。

自定义模板必须包含且只包含一次 `{text}`，保存后会用本次识别文字替换它。模板在本地应用，不会自行调用 AI。

## 词表与纠错

内置 **编程词表** 用于提示识别模型注意技术术语。自定义词汇每行一个，最多 100 项，每项最多 80 个字符；可添加项目名、产品名或常用术语。

**纠错对照** 每行一条，使用 `错误写法 => 正确写法`。纠错使用文字匹配，在本地处理识别结果；请只添加你需要的明确替换，避免宽泛规则误改其他词语。最多 100 条，单侧最多 80 个字符。

**导入 JSON / 导出 JSON** 包含词表预设、自定义词汇和纠错规则，不包含 AI 地址或密钥。导入后需要保存；导入文件上限为 64 KB。

## AI 改写

AI 改写默认关闭。启用步骤：

1. 在处理模式中选择 **AI 改写**。
2. 填写兼容 API 地址、模型 ID、改写提示和 API 密钥，然后保存。
3. 可点击 **测试连接** 检查接口；该操作发送固定测试句。

地址支持 OpenAI 兼容的 Chat Completions 接口，可填写服务基础地址、`/v1` 地址或完整的 `/chat/completions` 地址。远程服务要求 HTTPS，本机 loopback 服务可用 HTTP。请求超时可设为 5–60 秒。

**选择并保存 AI 模式后，后续转写会将文本和改写提示发送到该服务。** 音频识别仍在本地完成；AI 请求失败时保留本地结果并提示。恢复“轻度整理”等本地模式即可停止后续 AI 改写。

密钥保存后不会回显，输入框留空表示保留原密钥；清除操作需要点击清除并保存。有关存储保护和数据发送范围，见 [安全说明](../SECURITY.md)。

## 文本工具

设置中的文本工具提供插入逗号、插入空格、空格转逗号和逗号转空格。转换操作以明确选区或最近插入的语音片段为范围；没有可转换范围时会提示先选择文本。直接插入逗号或空格时，若没有选区，会追加到当前输入框末尾。

**恢复原始 / 恢复本地结果** 可恢复最近语音片段对应的文字。它们不会替换其他草稿内容；如果语音片段已经被改动或无法定位，请手动调整。

## 高级识别设置

- **后端**：自动、faster-whisper 或 MLX（Apple Silicon）。模型格式需要与后端匹配。
- **设备**：自动、CPU 或 CUDA；MLX 使用 Apple Silicon 的本地加速。
- **模型路径**：填写已下载的本地模型目录。设置页不会自动下载模型；安装时可通过 `-Model` / `--model` 选择预设。
- **解码、线程与空闲时间**：影响识别计算量和模型驻留时间；不确定时保留默认值。

改变模型或后端后，下一次任务可能需要重新加载。安装模型和运行环境的方法见 [安装指南](install.md)。
