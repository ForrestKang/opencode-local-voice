# 0.3.0 功能和接口

默认使用本地普通输入模式、编程词表、自动识别语言、自动标点、保持空格，AI 关闭。点击麦克风开始，Enter 结束，Esc 取消。仅在当前对话输入框内处理录音快捷键；输入法确认、修饰键和长按重复不会触发录音动作，普通空格不被监听。

原生“设置 → 语音输入”新增文本处理、词表/纠错、模板和折叠的文本工具。词表每行一个术语，纠错对照每行 `原词 => 目标词`；内置词汇用于识别提示，明确对照才执行后处理替换。导入/导出只包含带版本的词表规则，不包含模型配置、录音、业务文本或密钥。

文字处理顺序：原始识别 → 本地规则 → 所选模板或可选 AI → 当前草稿。原文模式保持识别结果；本地模式无需模型接口。自动规则避免改变代码、标识符、路径、URL 和数字。文本工具只处理明确选区或仍能确认的最近语音片段，草稿已修改或选区包含文件提及时要求重新选择。

AI 模式需要兼容的 Chat Completions API 地址、模型和可选密钥。允许 HTTPS 或本机回环 HTTP；拒绝跳转，避免把凭据发送给跳转目标。启用并保存 AI 模式后，录音转写会发送本次本地文字和改写提示；设置预览和连接测试仅在点击按钮时请求，连接测试使用固定句子。模型错误、超时、空结果或超限时返回本地结果和明确提示。

Windows `rewrite_api_key` 文件是当前 Windows 用户的 DPAPI 密文，macOS/Linux 使用权限 0600 文件。配置读取仅返回 `rewrite_key_configured`；保存空密钥清除，省略密钥字段保持原值。界面不读回明文。备份保留密文文件，勿把个人配置、凭据或 Web 配对脚本分享进仓库。

新增协议均需已有本地服务鉴权：

| 接口 | 请求/返回 |
|---|---|
| `POST /v1/text` | `{text, config?:文字规则, rewrite_api_key?:临时密钥}`，返回原文、本地结果、最终结果、提示、耗时；覆盖配置不持久化 |
| `POST /v1/rewrite/test` | `{config?:AI配置, rewrite_api_key?:临时密钥}`，用固定句测试连接；返回安全状态信息 |
| `POST /v1/jobs/<id>/use-local` | 仅在 AI 改写阶段停止该任务的优化，完成为本地结果，不重新识别录音 |

任务继续兼容 `text`，新增 `raw_text`、`local_text`、`processing_warning` 和分段耗时；改写期间状态为 `rewriting`。桌面客户端限制任务所属窗口；Web/TUI/CLI 共用同一服务管线。词表/文字处理共享，本机麦克风设备单独保存，未实现跨电脑云同步。

已有 Windows 安装的功能更新事务备份 ASAR、六个后台文件及配置/密钥；恢复前另存新版本配置，核对应用路径、版本和哈希后再恢复。模型、聊天、工作区和服务 token 不属于覆盖范围。macOS/Linux 保留各自安装与完整包恢复流程，本轮自动检查不代表真机运行验证。
