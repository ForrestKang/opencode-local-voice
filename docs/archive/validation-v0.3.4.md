# 0.3.4 OpenCode 更新后的格式兼容修复

本机 OpenCode 从 1.18.33 更新到 1.18.34，官方安装程序将整个 app.asar 替换，原有语音 renderer、bridge 和设置注入均消失。语音后台、模型及配置位于应用目录之外；本次检查没有要求重新下载模型。

此前 Repair-Voice 只有手动恢复能力，没有自动更新恢复钩子。1.18.34 的标准 ASAR 使用 Chromium Pickle 对齐，旧读取器错误地要求 JSON 头没有 padding，导致人工恢复也在读取阶段失败。本版支持标准零至三字节对齐并保留旧 compact 备份的读取能力，输出使用标准对齐；错误、过长、非零及截断 padding 均拒绝。

55 项 Node 自动检查通过，包含四种标准 padding、旧备份、错误输入、事务回滚与重复应用。1.18.34 实际原生控件与 CSS 的隔离浏览器 legacy/V2 共 24 项通过。实际 ASAR 的 6952 个 packed 条目完整性、五个生成脚本语法、未修改文件的字节保留与重复补丁一致性通过。providers 和对话框外壳为测试替身，未操作用户桌面 UI。

原生设置源文件与 0.3.3 完全一致；voice_server.py 和 oc-mic.js 仅改版本号。本轮没有真实麦克风、真实语音、外部 AI 或模型冷启动测试。安装事务保留 1.18.34 官方原包，禁止用 1.18.33 旧包回滚新版。

本版没有安装常驻更新守护、系统计划任务或自动修复钩子。未来官方更新仍会覆盖 ASAR；手动修复器仅在包格式、原生布局、语法及完整性门禁通过时重新应用，未知布局保留官方包并报错。不能把当前恢复验证称作未来版本自动保留的保证。

安装后的文件回读和实际启动证据保存在本机 test-results 及稳定维护目录，未混入发布包。
