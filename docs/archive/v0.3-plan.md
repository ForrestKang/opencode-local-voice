## 本次功能范围

| 功能 | 拟实现行为 | 初始默认 |
|---|---|---|
| 内置与自定义词表 | 内置编程技术词，支持自定义术语、别名和纠错对照及 JSON 导入／导出；识别前作为词汇提示，识别后按明确规则纠错 | 编程词表启用；不做激进的全局近音替换 |
| 本地提示词模板 | 普通输入、编程任务、问题分析预设；支持自定义模板和原文占位符，不补造需求或事实 | 本地处理启用，普通输入模板保持原有表达 |
| 默认语言与中英混输 | 复用已有自动／中文／英文识别选项，保存用户默认；中文叙述中的英文术语、大小写及标识符按词表保留 | 自动识别；不自动翻译 |
| 标点与空格规则 | 自动／中文／英文／不加标点；保持空格／智能整理／空格转逗号／逗号转空格，自动规则处理本次语音结果 | 标点自动、空格保持；其他转换由用户选择 |
| 固定录音快捷键 | 仅保留 Enter 结束、Esc 取消；开始录音用麦克风按钮。插入逗号／空格和执行转换通过按钮操作 | 普通空格保持原行为 |
| 可选 AI 改写 | 在同一设置页填写兼容 API 地址、模型、密钥和改写提示；支持本地兼容服务或云端接口，超时／异常回落本地结果 | 默认关闭；用户配置并主动启用 |

词表纠错和格式整理是确定性的本地操作。复杂语义整理由可选 AI 承担，二者在设置中清楚区分。

自动空格转换只作用于本次语音文本；手动文本转换优先作用于选区，其次仅作用于可确认的最近语音片段，不能确认范围时提示用户选中。普通空格和输入法拼字不被插件接管。

自动处理时，路径、URL、代码、数字、小数点、版本号、英文单词间空格和已有草稿作为重点保护对象。用户明确选中一段文本并手动执行转换时，按其选择处理该选区。全局替换与快捷键不得改变其他窗口或设置字段中的输入。别名匹配规则、优先级与边界需有可复现测试。

处理流程：识别结果 → 词表／格式处理 → 所选模板或可选 AI 优化 → 草稿。保留原始结果与本地结果，支持比较、恢复和失败回退；不会自动发送消息。

AI 启用后仅发送本次转写文本及配置的优化提示；设置中说明这一行为。密钥由本机后台保存，Windows 使用系统凭据保护，不在读取配置接口中回传明文，不进入前端缓存、日志、设置导出或发行包。

Desktop、Web、TUI 和 CLI 调用同一本地服务中的文字处理规则，相同输入与相同配置应得到一致结果。术语、文本规则与优化模式使用统一配置；麦克风设备和快捷键偏好按本机／平台保存。

本轮优先完成 Windows 桌面端的实际安装与运行检查；Web／TUI／CLI 做协议、配置和结果一致性联测。macOS／Linux 做平台分支、候选包与隔离测试，真实硬件验证按可用环境记录，不把静态通过当成真机通过。跨电脑云同步不属于本轮范围。
