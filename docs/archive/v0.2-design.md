# v0.2 修整设计与接口契约

本轮由用户授权处理上一轮审查发现的问题。只修改项目与生成候选包；自动化使用隔离目录、伪后端、合成音频、模拟安装包。真实设备、GPU/Metal、桌面安装和签名验证交给用户。

## 结构

- `shared/voice_server.py`：统一配置、认证、受限 HTTP、任务队列、可终止识别进程、faster-whisper/MLX 后端。
- `shared/desktop-bridge.cjs`：Electron 主进程接入，服务身份验证、进程生命周期、来源检查。
- `shared/oc-mic.js`：共用桌面/Web 界面，原生设置页内的语音面板、麦克风选择、预热、重试、状态、取消。
- `shared/browser-transport.js`：Web 接入同一本地服务；显式本机配对，凭据只保存在本机。
- `shared/voice_cli.py` 与 `extras/voice-input.ts`：跨平台文件/FFmpeg 录音接入和 TUI 草稿追加。
- 平台目录只保留安装、薄启动器、打包与回滚入口。

## 协议（版本 1）

配置根：`OPENCODE_VOICE_HOME` 或 `~/.config/opencode/local-voice`。
`config.json` 为唯一持久配置，旧环境变量只在首次初始化迁移；`token` 文件为随机凭据（POSIX 0600），不打包、不记录、不通过 config/status 返回。

服务固定监听 127.0.0.1，端口从配置 `port`（默认 47832）读取。默认端口的旧 OPENCODE_STT_LOCAL_PORT 只参与首次迁移。

- `GET /health?challenge=<随机nonce>` 不需要认证，返回 `{service:"opencode-local-voice",protocol:1,version:"0.2.1",proof:<HMAC-SHA256(token,nonce)>}`。客户端验证 proof 后才发送 bearer token 或录音，避免把凭据/音频发给占用端口的其他服务。
- 其余请求使用 `Authorization: Bearer <token>`，如带 Origin 必须匹配配置 allowlist。CORS 按已准许的 Origin 回显，不使用全局 `*`。
- `GET /v1/config` -> 配置对象。
- `PATCH /v1/config` JSON 配置补丁 -> 新配置；活动任务期间的配置修改返回 409。端口在服务运行时不修改，持久化和运行配置在同一协调锁内更新。
- `GET /v1/status` -> `{model_state,backend,device,queue_depth,version,last_error,...}`；不得包含 token 或转写文本。
- `POST /v1/warmup` -> `{id,state}`，去重的模型预热任务。
- `POST /v1/shutdown` 仅鉴权、零字节请求体且无活动/排队任务时可用，成功 HTTP 202 `{status:"shutting_down"}`；供安装器停止已核对身份的旧进程并部署新配置/代码，不向渲染器暴露。
- `POST /v1/jobs` body 为 16kHz/mono/s16 WAV，`X-Job-Id` 为调用者生成的 UUID -> HTTP 202 `{id,state}`。
- `GET /v1/jobs/<id>` -> `{id,state,text?,error?,timings?}`；state 为 queued/loading/transcribing/done/error/cancelled。
- `DELETE /v1/jobs/<id>` -> `{id,state:"cancelled"}`；排队任务移除，执行中任务终止识别子进程。支持短期取消 tombstone，处理取消先于上传的竞态。
- 可保留已认证的同步 `/inference` 兼容 CLI，但新接入统一用 jobs。没有第二次音频转写补标点。

配置字段：`backend` auto/faster-whisper/mlx；`device` auto/cuda/cpu；`model_path` 本地模型目录；`language` auto/zh/en/...；`beam_size` 默认 1（1..5）；`cpu_threads`；`max_seconds` 默认 120（5..300）；`idle_seconds` 默认 1800；`warmup_on_record` 默认 true；`initial_prompt` 自定义技术词；`allowed_origins` 默认 localhost/127.0.0.1 HTTP 端口；`port`。麦克风 deviceId 属于浏览器本机偏好，不写成跨客户端共享硬件标识。

后端 auto 在 Apple Silicon 使用 MLX，在其他环境使用 faster-whisper；自动下载只在安装器明确执行，服务使用本地模型、禁止推理期间隐式联网。CUDA 的加载和首次/后续推理失败都在 auto 模式尝试 CPU；显式 cuda 失败给出清楚错误。所有模型加载/推理放在可终止子进程中，主 HTTP 服务快速就绪。

## Electron 桥契约

`desktop-bridge.cjs` 导出 `install(electron, options?)`、`allowMedia(webContents, permission, details)` 和可注入依赖测试的 `createClient(options?)`。
原生 preload 暴露 `window.ocMic`：
`getConfig()`, `saveConfig(patch)`, `status()`, `warmup()`, `transcribe(bytes,mime,jobId)`, `cancel(jobId)`, `onProgress(callback)`（返回解除订阅函数）。
转写返回 `{text,timings,...}` 或 `{error,code}`。取消同时发给服务，转写轮询停止。
IPC 只接受主 frame，URL 为 `oc://renderer/...` 或安装包内的 file renderer；每个 sender 只可取消自己的任务。模型启动错误成为语音功能错误，不传播为宿主崩溃。
客户端关闭仅取消自己的任务，共用服务由空闲退出负责；同时启动服务发生端口竞争时，接受已通过身份校验的胜出进程。
补丁加载：`/*oc-voice-v2:start*/require2("./oc-voice-bridge.cjs").install(require2("electron"));/*oc-voice-v2:end*/`。
权限补丁保留宿主来源检查，仅通过 `allowMedia` 添加麦克风请求，不直接向权限 Set 添加 media/local-network-access。

## 补丁与回滚

共用打包器，输出前检查生成 JS 语法、文件数据与哈希；识别旧标记并安全迁移。生成与安装分开。备份按应用版本/源哈希组织，安装原子替换，失败恢复。回滚匹配当前安装与 manifest，拒绝跨版本混装。
macOS 保存整个原版 app bundle，包含 Mach-O/fuse/签名/扩展属性，原版恢复不重新签名。修改候选 bundle、校验签名后再换入；不全局清扩展属性或静默关闭 fuse。

## 验证与交付

Python HTTP/认证/限额/取消/配置与伪识别进程测试；Node 主进程桥与 ASAR fixture 测试；合成浏览器 DOM/音频交互；安装器语法与隔离 dry-run；平台包 SHA256/文件 manifest。报告明确区分自动化通过与真实平台待验证。

## 0.2.1 原生设置接入

ASAR 补丁检查 renderer assets 中唯一的新/旧 DialogSettings 组件，分别在快捷键后注册真正的 `TabsV2.Trigger`/`Tabs.Trigger` 和同值 `Content`（`voice-input`）。内容由 `oc-voice-settings` custom element 在连接时渲染，断开时释放并忽略迟到配置响应。原生 Tabs 管理 selection、ARIA、键盘导航、延迟挂载、滚动和对话框关闭。

不通过手工追加 DOM 伪造 Tab；未知或重复 settings bundle 布局拒绝构建。受管理的设置注入可更新/重入，所有替换的 bundle 更新 integrity 并通过 JS 语法检查。输入框不再有设置齿轮，renderer 不创建独立语音 dialog。Web 个人脚本保留录音，使用同一服务配置；原生 Tab 补丁适用于桌面 ASAR，不声称 userscript 修改了 Web 服务器的 bundle。
