# 0.3.3 设置页清理

按用户本轮明确要求，删除设置页的预览示例、处理效果、预览结果，以及最近语音的原始／本地／当前文字展示。同步删除默认示范内容、预览状态和回显订阅。页面保留实际配置、转换和恢复按钮，按钮仍调用既有草稿接口。

原生设置隔离浏览器的 legacy 和 V2 共 24 项通过，检查示例控件和识别全文不存在、预览 API 不被调用、文本转换及恢复仍可操作，并保存窄屏截图。设置控件与 CSS 来自实际 OpenCode ASAR；应用 providers 和设置外壳使用测试替身。

Node 53 项、JavaScript/TypeScript 源码检查通过。实际 ASAR 的 6954 个文件完整性、5 个主脚本解析和重复补丁一致性通过。recognition server 和录音 renderer 与冻结 0.3.2 源码相比，仅版本字符串更新，识别与录音逻辑没有变化，因此没有重复完整模型性能测试。

本轮没有录制真实麦克风、加载模型或请求外部 AI。安装后以应用日志确认 0.3.3 脚本加载，并对 ASAR、后台文件、配置和备份回读。安装前 0.3.2 单独保留。
